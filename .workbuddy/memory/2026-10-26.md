# 2026-10-26 工作日志

## git push 调试（主页仓库 CPW-LittlePear.github.io）
- 背景：commit `f32b2e9`（新增网易雷火《无限大》玩法策划实习经历）此前卡在本地未推送。
- 根因：git 不读系统/IE 代理，只认 `git config http.proxy` 或 `http_proxy` 环境变量。本机 IE 代理真实端口是 **7892**（旧记忆记为 7890，已过期）。沙箱内 `127.0.0.1` 指向沙箱自身，故 7890/7892 均不可达；直连 github:443 被 GFW 干扰超时（21s）。PowerShell `Invoke-WebRequest` 能通是因为它读 IE 系统代理。
- 解决：在真实环境（`dangerouslyDisableSandbox`）下执行 `git config --global http.proxy http://127.0.0.1:7892` 后 `git push origin main` 成功，推送区间 `6e4c8b9..f32b2e9`，`origin/main` 已与 `HEAD` 同步。
- 已更新 MEMORY.md：代理端口 7890 → 7892，并注明 git 须显式配置代理、需在真实环境推送。
